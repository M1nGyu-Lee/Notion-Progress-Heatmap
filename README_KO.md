# 수업 날짜 기준 잔디

페이지 생성일 대신 **`Date` 날짜 속성**으로 잔디를 표시합니다.

- `Date`가 없거나 비어 있으면 집계에서 제외합니다. 생성일로 대체하지 않습니다.
- 날짜만 입력했다면 그대로 사용합니다. 시간이 포함되면 한국 시간(Asia/Seoul)으로 집계합니다.
- 제목이 `[DAY 33~45]`이면 `Date`에 **DAY 33의 실제 날짜 하나**만 입력합니다. 시작·끝 DAY를 포함해 13일을 토·일요일을 건너뛰며 표시합니다. 예: `Date = 2026-11-05` → 11월 5일부터 11월 23일까지 평일 13칸.
- `DAY33~45`, `DAY 33 ~ DAY 45`, 소문자, 전각 숫자, `～`, `〜`, `-`, `–`, `—` 구분자를 인식합니다. 제목이 여러 서식 조각으로 나뉘어 있어도 합쳐서 읽습니다.
- 유효한 DAY 범위가 있으면 `Date.end`보다 제목의 수업일 수를 우선합니다. 시작일이 주말이면 다음 월요일부터 셉니다. **공휴일은 별도 제외하지 않습니다.**
- 제목에 DAY 범위가 없는 기존 기록은 그대로 동작합니다. 단일 날짜는 그 날짜만, 명시적 Date 범위는 시작·종료일을 포함한 모든 날짜를 표시합니다. 잘못된 종료일은 시작일만 사용합니다.
- 제목만으로 실제 시작 날짜를 추정하지 않습니다. Date가 비어 있으면 범위 제목이 있어도 표시하지 않으며, 기존 Notion 페이지와 속성은 수정하지 않습니다.
- 같은 날 여러 기록이 있으면 가장 높은 Progress를 사용합니다. Progress가 비어 있으면 기존 동작처럼 100으로 처리합니다.
- `ENV_DATABASE_ID`에 지정한 원본 데이터베이스만 조회하며, 100개 이후 기록도 이어서 조회합니다.

## 설정과 검증

기존 `ENV_NOTION_TOKEN`과 `ENV_DATABASE_ID`를 사용합니다. `ENV_DATABASE_ID`는 대시보드 페이지 ID나 보기 ID가 아닌 원본 데이터베이스 ID여야 합니다. 토큰이 이 데이터베이스를 읽을 수 있어야 합니다.

Notion API 버전은 다중 데이터 소스를 지원하는 `2025-09-03`으로 고정했습니다. [공식 전환 가이드](https://developers.notion.com/guides/get-started/upgrade-guide-2025-09-03)를 따릅니다.

`npm test`로 DAY 범위의 평일 계산, 제목 표기 변형, 연도 경계, Date.end 우선순위, 빈 날짜, 한국 시간 날짜 경계, 중복 날짜, 여러 데이터 소스 및 페이지네이션을 검증합니다.
